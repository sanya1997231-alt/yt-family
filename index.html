Пароль входу на сайт

Після зміни пароля завантажте оновлений файл index.html нижче.

Як опублікувати на GitHub Pages за 2 хвилини:
  1. Натисніть зелену кнопку вище та збережіть файл index.html.
  2. Зайдіть на github.com → натисніть New repository → назвіть, наприклад, yt-family (оберіть Public) → натисніть Create repository.
  3. Натисніть uploading an existing file → виберіть ваш index.html → натисніть Commit changes.
  4. Зайдіть у Settings → Pages → у пункті Branch виберіть main і натисніть Save.
  5. Через 1 хвилину з'явиться постійне посилання вигляду https://ваш-нік.github.io/yt-family/.
